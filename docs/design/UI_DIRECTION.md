# 整体设计方向记录

日期：2026-09-09。状态：本方向已纳入 [design.md 1.4](../../design.md) 并落实到共用前端与 Electron 窗口。本文保留方向形成、问题与验收记录；具体配色、尺寸及工程边界以 design.md 为准。

## 设计定位

**安静、清晰、有秩序的 Agent 工作空间。**

采用具有桌面工具感的现代极简风格：纸白内容面、石墨灰文字、松绿色强调。通过布局、留白和文字层级建立专业感。会话以阅读与输入为中心，管理页面以扫描与配置为中心，共用同一套导航、颜色和控件语言。

风格关键词：克制、柔和、精确、内容优先。避免大面积彩色背景、渐变、玻璃效果、装饰性光晕、卡片套卡片，以及到处出现的绿色成功标签。

## 调整前截图揭示的问题

截图来自独立浏览器测试服务，含模拟 Agent 与测试会话，不代表真实模型运行。截图仅用于本轮设计检查，发布前按要求清理。现已补齐新会话、连续对话、Agent 列表、模型配置、Agent 运行、共享资源、运行观测及系统信息的 1440px / 390px 截图。调整前手机证据不完整，不补造对比图。

| 层面 | 现象 | 风格层面的调整 |
| --- | --- | --- |
| 空间 | 会话页同时出现 208px 主导航与 240px 历史栏 | 合并为一个约 272px 的侧栏，让内容成为空间主体 |
| 层级 | 主导航、历史筛选、执行筛选和对话工具栏逐层占据注意力 | 主导航稳定；上下文紧邻内容；诊断操作渐进展开 |
| 色彩 | 页面大面积相近灰白，绿色同时用于导航与大量完成标签 | 用明确的表面层级区分导航与正文，绿色集中在主动作和品牌 |
| 控件 | 深色描边输入框与多个小图标形成较强的表单感 | 输入区成为整体，次级控件使用低强调样式，重要输入保持可辨识边界 |
| 历史 | 标题易截断，没有时间组织，状态比标题醒目 | 按时间组织文本行，标题优先，Agent 与时间为次级；异常状态提高显著性 |
| 底部 | 侧栏展开时仍只有一个孤立的折叠图标 | 展开时统一为图标加文字的整行操作，收起时统一图标尺寸与对齐 |
| 一致性 | 管理、观测、设置的内容起点与分组表达不同 | 统一标题区、工具栏、分隔和页边距；按内容类型选择表格或表单分组 |

## 字体与形状

- 保留本地 Geist 与中文系统字体。中文长文优先舒适行高，代码与路径使用等宽字体。
- 页面标题 22–24px / 32px，区域标题 15–16px / 24px；导航与表单 14px / 22px；对话正文 15–16px / 26px；必要元信息不小于 12px。
- 常规字重 400，标签和操作 500，重要标题 600。避免全页面粗体和大面积小字。
- 间距沿用 4px 刻度，主要采用 8、12、16、24、32px；通过接近程度表达归属。
- 控件圆角 8px，输入面与弹层 12px，状态标签 4–6px。列表区域保持平直；不把所有对象变成胶囊。
- 按钮默认高 36px，导航行 40px，触控目标至少 44px。图标统一 Lucide 线性风格，常规 16–18px。
- 阴影仅用于菜单、抽屉、弹层。内容面和表格用背景与分隔建立层级。

## 统一空间结构

桌面工作区：`单一侧栏 272px | 连续主内容区`。侧栏可收起为 64px 图标栏；历史入口仍可直接访问。详细任务信息按需使用右侧面板，默认不挤占对话。

侧栏从上至下为品牌、主模块导航、当前模块上下文、底部辅助操作。会话模块的上下文即历史列表，与主导航共用一栏；历史单独滚动，底部操作固定可达。系统信息和折叠操作位于底部，并采用一致的行高、左右缩进与图标起点。

顶栏只承载当前上下文和必要操作。网关健康以低强调方式展示，异常时升级为明确提示。避免反复展示“会话 / 完整对话 / 对话”等同义标题。

窄屏使用一个主导航抽屉；从对话可直接打开历史。主内容单列，输入和必要操作保持可达。目标断点见 design.md 第五节，后续结合抽屉、键盘与最小宽度验证。

## 各类页面如何使用同一风格

| 页面类型 | 视觉主角 | 组织方式 |
| --- | --- | --- |
| 新会话 | 输入框 | 简短欢迎标题，输入面下接 Agent、目录和高级设置；首次提交前始终可发现必填目录 |
| 连续对话 | 正文与当前输入 | 阅读宽度约 720–800px，回答以无外框长文呈现，用户消息用低对比背景；工具信息可展开 |
| 历史会话 | 会话标题 | 时间分组，安静的文本行；当前项用选中背景与字重，完整名称可通过键盘与指针查看 |
| Agent / 共享资源 | 名称、可用性、操作 | 连续表格或列表，统一列对齐；配置、版本和模型参数按需展开 |
| 运行观测 | 异常和关键指标 | 指标带、趋势、表格；图表色用于数据语义，空白与无数据各有明确说明 |
| 系统设置 | 字段与保存动作 | 单层分组，标签先于帮助文字；低频配置折叠，集中显示未保存和生效状态 |

## 交互语气

主要动作使用实心松绿按钮；次级动作使用中性弱底色或描边；辅助动作使用文字或图标按钮。删除只在确认或明确危险操作处使用红色强调。

展开的侧栏提供“图标 + 收起侧栏”整行入口；折叠后为同轴图标加 Tooltip。必要操作不依赖 hover 才出现；键盘焦点独立于 hover，并与选中状态区分。

过渡使用 120–180ms 的颜色或透明度变化，尊重减少动态效果偏好。加载、保存中、错误、无结果与禁用均有明确文字反馈。

1. 已将视觉规则与 2026 年官方工程实践写入根目录 design.md，并同步 FRONTEND.md 的导航与历史目标。

## 本轮实现与验收

- tokens.css 统一纸白 / 暖灰 / 石墨 / 松绿语义色；控件圆角、输入面、焦点环和开关点击区域在基础组件集中维护。index.css 共享布局进入 components 层，合并同级重复定义，调用点使用 utility 管理响应式显示。
- 主导航与历史合并为 272px 侧栏；收起后为 64px 图标栏，历史从共用 Sheet 访问。系统信息与折叠操作位于底部，展开时有完整文字。历史按本地日期分组、标题最多两行且可查看完整名称，进入详情保留搜索、状态与游标。
- 新会话采用紧凑上下文布局；对话阅读宽度上限 800px，输入持续可达。右侧信息栏只有在能保留至少 720px 对话区时展开，缩窄时收起。Agent、资源、观测和设置沿用连续表格 / 单层分组，共享间距与表面语义；手机长观测标签改为 Select，表格以紧凑字段行展示。
- Electron 保留原生窗口控件，通过 nativeTheme 同步主题和窗口底色；网关事件状态与版本显示在固定底栏。主内容保留原生滚动条与对称预留空间，Base UI 滑块增强对比和高对比模式适配。
- 浏览器完整回归 84 项通过、4 项按项目条件跳过；覆盖浅深色、320–1920px 布局、键盘、减少动态效果、放大文字、历史、审批、配置及保存失败。最终表格和信息栏调整的相关回归另有 14 项通过、2 项矩阵重复条件跳过。截图采集的 16 个页面 / 视口组合均无页面脚本错误与横向溢出。
- 发布前后端测试 86 项通过、6 项按环境条件跳过。类型检查、lint、生产构建、Linux 目录包构建通过。Electron 开发态及移到仓库外的包体冒烟检查主题、760×560 内容区、状态栏、滚动区、偏好恢复及原有安全 / 网关流程。图形测试使用 Xvfb 和测试用 no-sandbox；生产仍保持 sandbox 与 contextIsolation。
- 测试过程中 /tmp 空间不足曾造成 Chromium 请求失败和包体复制失败；运行缓存与截图均改放磁盘目录后重跑通过。Windows/macOS 原生窗框、系统菜单和签名包未在本轮实测；模拟 Agent 结果不代表真实模型验收。

临时截图、浏览器运行缓存与本地打包产物在 0.1.11 发布前按要求清理，不纳入产品资源。需要复现时运行 `code/test/browser.spec.ts` 与 `code/test/desktop-smoke.mjs`；可通过 `AGENT_UI_ARTIFACT_DIR` 指定截图输出目录。
